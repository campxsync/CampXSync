# Repository Rules

## Document & Script File Locations
- **Documents**: Whenever documents (e.g., `.docx`, `.pdf`, `.md` report files, documentation files) are created, place them in the `docs/` folder (or relevant subfolders in `docs/`).
- **Document Generation Scripts**: Whenever document generation scripts (e.g., Python scripts for generating `.docx` or reports) are created, place them in `scripts/doc_generators/`.
